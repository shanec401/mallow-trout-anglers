Members & admins

Admins added here can create competitions and approve join requests inside this app. The very first admin has to be added by hand in the Firestore console (Firestore Database → "admins" collection → add a document whose ID is your user ID) — after that, admins can promote others from this screen.

Backup

Firebase's free plan doesn't keep automatic backups — if something gets deleted by mistake, there's no built-in undo. This downloads everything (catches, competitions, registrations, roster, admin list) into one file as a safety copy. Worth doing every so often, and definitely before any big cleanup.

Privacy

This app stores personal data — names, emails, phone numbers, locations, and fee status for club members, plus catch records and photos. Only admins can see the Anglers roster; regular members only see names and catch activity, not contact details or fees. If someone asks to have their data removed, use "remove" on their roster entry, and ask them to use "Delete my account" next to their name at the top of the app if they also want their sign-in and catch history erased.
